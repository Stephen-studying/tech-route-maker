# 校园源网荷储协同优化项目简要说明

## 系统建模

- 校园负荷与光伏资源
- 源网荷储系统边界
- 协同优化目标定义

## 状态预测

- 光伏出力短期预测
- 校园负荷短期预测
- 储能 SOC 状态估计

## 优化决策

- 经济、低碳与可靠性目标
- 源储荷协同调度
- 并网功率与设备约束

## 仿真验证

- 典型日运行仿真
- 极端天气压力测试
- 基线策略对比验证

## 评价应用

- 经济性与减排评价
- 供能可靠性评价
- 运行策略与实施建议

## 研究方法

项目采用文献调研与理论分析、数据驱动预测、多目标优化与约束求解、场景仿真与对比实验以及综合评价方法。

## 项目背景

本项目面向校园综合能源系统，研究光伏、储能、负荷与电网之间的协同运行。目标是在满足设备和并网约束的条件下，提高供能可靠性，降低运行成本与碳排放，并形成可实施的运行策略。
